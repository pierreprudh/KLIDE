# Vibe approval icons

Native Vibe pixel artwork for Ask, Accept Edits, Smart Approve and Auto Approve.
The SVG geometry comes from the corresponding `*PixelIcon` components in the
installed Vibe desktop app's approval selector. Keep these as vectors so they
render consistently across platforms, without depending on system emoji fonts.

The Mistral brand mark remains the agent identity; these identify its selected
approval mode.
